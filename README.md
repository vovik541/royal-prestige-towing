# Royal Prestige Towing

Website for Royal Prestige Towing, an owner-operated vehicle and equipment transport business in Sacramento, California.

- `web/` — the production website (Angular SSR, English / Ukrainian / Russian). See [web/README.md](web/README.md) for development, build and Cloudflare deployment.
- `IMG_*.jpg`, `sergei.jpg` — the client's original photographs. `web/scripts/build-images.py` crops them into the WebP images the site uses.
